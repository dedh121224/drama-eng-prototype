# 劇聽英文 DramaTalk 🎧

專為台灣人聽力與口說弱點設計的**「港式中英夾雜單元劇」**靜態網頁學習原型。

> **線上體驗（GitHub Pages）**：https://dedh121224.github.io/drama-eng-prototype/

---

## 核心設計理念

1. **低阻力情境輸入**：以現代都會職場短劇為主幹（首章：《星辰集團生存日記 EP01》——冷面霸道總裁顧景深 × 苦命打工人林小滿），在中文對話中自然夾雜高頻英文片語。
2. **整句連同括弧中文一起唸出來**：
   - 例如：「這件事您真的 **take it for granted**（視為理所當然） 了！」
   - 系統會透過瀏覽器內建 **Web Speech API** 自動將中文段落、英文片語與括弧內的中文釋義接續朗讀，不需要盯著螢幕查字典，通勤、做家事時光靠「聽」就能建立聲音與語意的直接連結。
3. **雙語分軌語音引擎**：
   - 中文與中文釋義採用 `zh-TW` 台灣國語聲線，英文片語自動切換 `en-US` 美式原生發音，並依角色性格微調音高與語速（亦可於設定切換為單軌相容模式）。

---

## 主要功能

- **🎧 聽劇對話播放器**：
  - **預設唸出括弧中文**（可隨時一鍵切換開/關）
  - **跟讀停頓（Shadowing Pause）**：每句包含英文片語的對白唸完後自動倒數 2～5 秒，留白讓你開口跟讀
  - **英文片語連唸兩遍（英文×2）** & **獨立調整英文語速**
  - **三階段聽力模式**：`雙語直聽` → `遮蔽中文` → `盲聽字幕`（點擊模糊處可偷看）
  - **RWD 響應式版面**：桌機雙欄（左劇情＋右焦點片語卡）、手機單欄＋底部懸浮播放列＋上滑片語詳解抽屜
- **🗣️ 單字與口說練習**：
  - 整理本集 12 個實戰片語，附台灣人常見中式英文地雷與連音訣竅
  - 支援瀏覽器麥克風跟讀檢測（Web Speech Recognition）與待複習收藏
- **🎯 音訊優先聽力測驗**：
  - 支援「聽英文片語選中文」與「聽劇情原句（自動關閉中文提示）選意思」，可針對錯題重練
- **💾 本機儲存與備份**：所有收藏、進度與設定皆存於 `localStorage`，並提供 JSON 匯出／匯入功能。

## 本機執行方式

本專案為純靜態 HTML / CSS / Vanilla JS（零建置步驟、無須安裝套件）：

1. 直接用瀏覽器開啟 `index.html` 即可試玩，或使用任意靜態伺服器啟動：
   ```bash
   npx serve .
   ```
2. 建議使用最新版 **Chrome / Edge / Safari** 以獲得最佳的 `zh-TW` 與 `en-US` 語音品質。

## 如何新增下一集劇本（EP02）

只需編輯 [`data/episodes.js`](data/episodes.js)，在 `DRAMA_DATA.episodes` 陣列中新增劇集物件，並在對白中使用標記語法：

```text
{{英文片語|中文釋義|vocabId}}
```

例如：

```text
"這件事我真的 {{take it for granted|視為理所當然|v07}} 了。"
```

前端與雙語語音引擎會自動解析成可點擊的互動片語與雙語分段語音。
